# Portfolio Ficticio
Proyecto desarrollado como práctica de **Desarrollo de Aplicaciones Web (DAW)**.

El objetivo es crear un portfolio personal ficticio utilizando únicamente **HTML** y **CSS**, aplicando buenas prácticas de estructura, semántica, accesibilidad y diseño responsive.
## Descripción
La aplicación consiste en una página web de portfolio en la que se presenta un personaje ficticio, su perfil profesional y una selección de sus proyectos.

La web estará diseñada para adaptarse a diferentes tamaños de pantalla y contará con distintas secciones para organizar el contenido.

## Estructura del proyecto
portfolio-ficticio:
- /index.html
- /styles.css
- /README.md

## Tecnologías utilizadas
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

## Secciones
La página estará formada por las siguientes secciones:
- Header y navegación
- Hero
- Sobre mí
- Portfolio
- Contacto
- Footer

La sección de portfolio incluirá una galería con diferentes proyectos ficticios.

## Características
El proyecto aplicará diferentes buenas prácticas de desarrollo web:
- Uso de HTML semántico.
- Separación entre estructura HTML y estilos CSS.
- Variables CSS mediante :root.
- Organización del CSS por secciones.
- Uso de Flexbox y CSS Grid.
- Diseño responsive mediante media queries.
- Uso de atributos alt para mejorar la accesibilidad.
- Metadatos HTML para descripción, autor y palabras clave.

## Diseño responsive
La interfaz estará adaptada para su correcta visualización en:
- Escritorio
- Tablet
- Dispositivos móviles
